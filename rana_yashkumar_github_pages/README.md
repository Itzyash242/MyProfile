# Rana Yashkumar — Portfolio Website

This is a static, responsive portfolio website. It uses only HTML, CSS, and JavaScript, so it does not require XAMPP, PHP, MySQL, or any backend server to display.

## Publish it with GitHub Pages

1. Sign in to https://github.com/
2. Click **New repository**.
3. Name the repository `rana-yashkumar-portfolio` (or another name).
4. Set it to **Public**, then create the repository.
5. Click **Add file → Upload files**.
6. Upload `index.html` from this folder. You can also upload this README.
7. Click **Commit changes**.
8. Open the repository's **Settings → Pages**.
9. Under **Build and deployment**, select **Deploy from a branch**.
10. Select branch **main** and folder **/(root)**, then click **Save**.
11. Wait a few minutes. GitHub Pages will show a published website URL on the Pages settings screen.
12. Open that published `https://...github.io/...` link on another phone or computer. Do not use `localhost`—localhost only opens a website on the same device.

## Features

- Responsive layout for desktop and mobile
- Navigation links to About, Skills, Education, Training, and Contact
- Contact links for email and phone
- LinkedIn link
- Save as PDF button (opens the browser's print dialog; choose “Save as PDF”)

## Before publishing

Check that your email, phone number, LinkedIn URL, education, and training details are correct. The profile circle currently displays the initials “YR”; no profile photo is required.

## Troubleshooting

- If the published URL shows a 404, confirm that `index.html` is in the repository root and GitHub Pages is enabled for `main` / `/(root)`.
- Wait a few minutes after saving Pages settings, then refresh.
- Use the exact GitHub Pages URL shown in **Settings → Pages**.
- A local address such as `http://localhost/...` is not public and cannot be opened from another device.
